# データ設計書

## 1. 概要

### 目的

Chinese Output Trainer において、

- ユーザー情報
- 簡体中文（普通話）の問題情報
- 繁體中文（台湾華語・國語）の問題情報
- 簡体中文・繁體中文それぞれのお気に入り情報
- 簡体中文・繁體中文それぞれの学習履歴
- AI生成問題
- AI問題生成に必要な制御情報

を管理するためのデータ構造を定義する。

本システムでは、簡体中文（普通話）と繁體中文（台湾華語・國語）を単なる文字体系の違いとして扱わず、**それぞれ独立した問題データ群として管理する**。

そのため、

- Question
- Favorite
- StudyHistory
- AiGeneratedQuestion

については、簡体中文用と繁體中文用でそれぞれ別のエンティティを持つ。

一方、ユーザー情報は共通とし、1つのユーザーアカウントから両方の学習機能を利用できるものとする。

また、AIによって生成された問題は、通常学習で利用するマスタ問題とは明確に分離する。

AI生成問題は生成された時点では永続化せず、**ユーザーが Hard / Good / Easy のいずれかの理解度を与えた場合に限り保存する**。

保存されたAI生成問題は、その問題を生成したユーザー専用の問題として扱い、他のユーザーの通常学習や復習には使用しない。

## 3. エンティティ概要

### User

ユーザー認証および権限を管理する。

#### 保持情報

- ユーザーID
- パスワード
- 権限

#### 権限

以下の権限を想定する。

- `USER`
- `ADMIN`

`ADMIN` を持つユーザーのみ、アドミン専用画面へアクセスできる。

#### 補足

Userは簡体中文・繁體中文で共通とする。

1つのユーザーが、

- 簡体中文マスタ問題の学習履歴
- 繁體中文マスタ問題の学習履歴
- 簡体中文マスタ問題のお気に入り
- 繁體中文マスタ問題のお気に入り
- 簡体中文のAI生成問題
- 繁體中文のAI生成問題

をそれぞれ独立して持つ。

---

### SimplifiedQuestion

簡体中文（普通話）の通常学習およびAI生成の基となるマスタ問題を管理する。

#### 保持情報

##### 基本情報

- 問題ID
- 日本語文
- 簡体中文の模範解答
- 別解（任意）
- 条件
- 難易度

##### AI生成情報

- AI生成用テンプレート

- 動詞生成タイプ
- その他AI生成に必要となる制御情報

#### 補足

通常学習ではSimplifiedQuestionに登録された問題のみを出題する。

AIによって生成された問題をSimplifiedQuestionへ追加することはしない。

## 4. AI生成制御情報

### AI生成可否

問題ごとに、AIによるバリエーション生成を許可するかどうかを管理する。

例：

```text
allow_ai_variation
```

| 値 | 意味 |
| --- | --- |
| `true` | AI生成問題の基となるマスタ問題として利用可能 |
| `false` | 固定問題としてのみ利用する |

すべての問題をAI生成対象にはしない。

専門的な文脈や固有の状況に強く依存し、一部を置き換えることで意味や自然さが崩れやすい問題については `false` とする。

---

### AI生成用テンプレート

AI生成対象となる問題には、必要に応じてテンプレートを保持する。

例：

```text
{{SUBJECT}}也稍微考慮一下{{TARGET}}的平衡嘛！
```

AIは原則として `{{...}}` で囲まれた部分のみを変更し、それ以外の文法・語順・表現を維持する。

使用するプレースホルダとして、以下のようなものを想定する。

```text
{{SUBJECT}}
{{VERB}}
{{OBJECT}}
{{TARGET}}
{{PLACE}}
{{TIME}}
{{PERSON}}
{{NUMBER}}
{{REASON}}
{{METHOD}}
{{ADJECTIVE}}
{{ADVERB}}
```

---

### 主語生成タイプ

`{{SUBJECT}}` を使用する問題では、必要に応じて主語の生成タイプを保持する。

| 値 | 意味 |
| --- | --- |
| `PRONOUN` | 代名詞を使用する方が自然 |
| `NON_PRONOUN` | 名詞句・固有名詞・無生物主語などが自然 |
| `ALL` | 代名詞・代名詞以外のどちらでも自然 |
| `NULL` | 主語制御不要、またはAI生成対象外 |

#### `PRONOUN`

元文の `SUBJECT` が担う意味的・談話的役割を維持した場合、代名詞を使用する方が自然な問題。

#### `NON_PRONOUN`

元文の意味的役割を維持する場合、名詞句・固有名詞・無生物主語などを使用する方が自然な問題。

#### `ALL`

元文の意味的役割を維持したまま、代名詞・代名詞以外のどちらを使用しても自然な問題。

---

### 動詞生成タイプ

`{{VERB}}` を使用する問題では、必要に応じて動詞表現の変更可否を保持する。

| 値 | 意味 |
| --- | --- |
| `FIXED` | 原文の時間・アスペクト・モダリティ上の役割を維持する |
| `FLEXIBLE` | 文章全体が自然であれば変更してよい |
| `NULL` | 動詞制御不要、またはAI生成対象外 |

中国語では英語のような時制による動詞活用だけでなく、

- `了`
- `過`
- `正在`
- `已經`
- `一直`
- `曾經`
- `會`
- `要`

などによって、完了・経験・進行・継続・未来などを表現する。

そのため、単純な `TENSE` ではなく、より広い概念として動詞表現を制御する。

## 5. お気に入り

### SimplifiedFavorite

簡体中文のマスタ問題に対するユーザーのお気に入り登録を管理する。

#### 保持情報

- ユーザーID
- 簡体中文問題ID

#### 主キー

```text
(user_id, question_id)
```

複合主キーとする。

#### 補足

- UserとSimplifiedQuestionの中間エンティティとなる。
- お気に入り登録された問題のみレコードを保持する。

- お気に入り解除時は対象レコードを削除する。
- 繁體中文側のお気に入り状態とは独立して管理する。

## 7. AI生成問題

### 基本方針

AI生成問題はマスタ問題とは別のデータとして管理する。

AIによって問題が生成された時点ではDBへ保存しない。

ユーザーが生成された問題に対して、

- `HARD`
- `GOOD`
- `EASY`

のいずれかの理解度を与えた場合に限り、AI生成問題専用テーブルへ保存する。

これにより、単に表示されただけのAI生成問題が大量にDBへ蓄積されることを防ぐ。

また、保存されたAI生成問題には必ず生成したユーザーのIDを保持し、そのユーザー専用の問題として管理する。

AI生成問題は通常学習用のQuestionテーブルへ追加しないため、他ユーザーの通常学習に混入することはない。

---

### SimplifiedAiGeneratedQuestion

簡体中文のAI生成学習で生成され、ユーザーから理解度を与えられた問題を管理する。

#### 保持情報

- AI生成問題ID
- ユーザーID
- 生成元となった簡体中文マスタ問題ID
- 日本語問題文
- 簡体中文の模範解答
- 評価
- 作成日時
- 評価更新日時

#### 主キー

- AI生成問題ID

#### 外部キー

- `user_id` → User
- `source_question_id` → SimplifiedQuestion

#### 補足

- AIが問題を生成しただけではレコードを作成しない。
- ユーザーが理解度を選択した時点で初めて保存する。
- 保存された問題は `user_id` のユーザーのみ利用できる。
- 他のユーザーから参照・出題されることはない。
- 通常学習では使用しない。
- 復習メニューからAI生成問題を対象として選択した場合に再出題できる。
- 評価を変更した場合は同一レコードの評価を更新する。
- 生成された問題そのものを保存するため、再度同じ文章を復習できる。

---

## 8. AI生成問題の保存フロー

AI生成問題の保存は以下の流れとする。

```text
マスタQuestionからAI生成
        ↓
AI生成問題をユーザーへ表示
        ↓
ユーザーが回答を確認
        ↓
Hard / Good / Easy を選択
        ↓
AiGeneratedQuestionへINSERT
        ↓
ユーザー専用の復習対象となる
```

理解度を与えずにAI生成学習を終了した場合は、その問題を永続化しない。

```text
マスタQuestionからAI生成
        ↓
AI生成問題をユーザーへ表示
        ↓
理解度を登録せず終了
        ↓
DBには保存しない
```

## 9. AI生成問題とマスタ問題の役割分担

### マスタ問題

以下のテーブルで管理する。

```text
SimplifiedQuestion
TraditionalQuestion
```

マスタ問題は管理者が登録・編集する、アプリケーション共通の公式問題である。

用途：

- 通常学習
- 復習
- AI生成の基となる問題
- ユーザー用問題一覧
- 管理者による問題管理

---

### AI生成問題

以下のテーブルで管理する。

```text
SimplifiedAiGeneratedQuestion
TraditionalAiGeneratedQuestion
```

AI生成問題は特定ユーザーのAI学習によって生成された個人用問題である。

用途：

- AI生成学習
- AI生成問題の復習

以下には使用しない。

- 他ユーザーへの出題
- 通常学習
- マスタ問題一覧
- AI生成元のマスタ問題としての利用

## 10. 復習時のデータ取得方針

復習では、ユーザーが出題対象を選択できるようにする。

例：

```text
出題元

□ マスタ問題
□ AI生成問題
```

マスタ問題を選択した場合は、

- SimplifiedStudyHistory
- TraditionalStudyHistory

を利用して対象問題を取得する。

AI生成問題を選択した場合は、

- SimplifiedAiGeneratedQuestion
- TraditionalAiGeneratedQuestion

から、ログインユーザー自身の問題のみを取得する。

さらに、

- 難易度
- 理解度
- お気に入り条件
- 出題順

などの既存の復習条件と組み合わせることを想定する。

ただし、AI生成問題にはマスタ問題と同じ属性がすべて存在するとは限らないため、AI生成問題に適用可能な復習条件については詳細設計時に確定する。

## 11. 簡体中文・繁體中文の分離方針

本システムでは、簡体中文と繁體中文を別の問題データセットとして扱う。

これは、

```text
簡体字 ⇔ 繁体字
```

という単純な文字変換を行うためではない。

普通話と台湾華語では、

- 使用される文字
- 単語
- 言い回し
- 慣用表現
- 自然な模範解答
- 別解
- AI生成テンプレート
- AI生成時に使用すべき語彙

などが異なる場合がある。

そのため、マスタ問題について、

```text
SimplifiedQuestion
TraditionalQuestion
```

を別々に管理する。

お気に入りについても、

```text
SimplifiedFavorite
TraditionalFavorite
```

に分離する。

学習履歴についても、

```text
SimplifiedStudyHistory
TraditionalStudyHistory
```

に分離する。

AI生成問題についても、

```text
SimplifiedAiGeneratedQuestion
TraditionalAiGeneratedQuestion
```

に分離する。

例えば、

```text
SimplifiedQuestion.question_id = 100
```

と、

```text
TraditionalQuestion.question_id = 100
```

に意味的な対応関係が存在することは保証しない。

両者は完全に独立した問題ID体系として扱う。

## 12. AiSetting

AI問題生成に関するアプリケーション共通設定を管理する。

### 保持情報候補

- 使用するAIモデル
- 共通プロンプト
- 簡体中文向け追加プロンプト
- 繁體中文向け追加プロンプト
- その他AI生成に関する共通設定

### 補足

問題単位のAI生成条件は、

- SimplifiedQuestion
- TraditionalQuestion

が保持する。

AiSettingは、問題個別ではなくアプリケーション全体で共有するAI設定を管理する。

ただし、これらをDBテーブルとして管理するか、

- `application.yml`
- `resources/prompts/`
- JSON
- Properties

などで管理するかは詳細設計時に決定する。

## 13. リレーション概要

### 簡体中文側

- User と SimplifiedFavorite は 1対多  
  1人のユーザーは複数の簡体中文マスタ問題をお気に入り登録できる。

- SimplifiedQuestion と SimplifiedFavorite は 1対多  
  1つの簡体中文マスタ問題は複数ユーザーからお気に入り登録される可能性がある。

- User と SimplifiedStudyHistory は 1対多  
  1人のユーザーは複数の簡体中文マスタ問題について学習履歴を持つ。

- SimplifiedQuestion と SimplifiedStudyHistory は 1対多  
  1つの簡体中文マスタ問題は複数ユーザーによって学習される。

- User と SimplifiedQuestion は SimplifiedFavorite を介して多対多の関係を持つ。

- User と SimplifiedQuestion は SimplifiedStudyHistory を介して多対多の関係を持つ。

- User と SimplifiedAiGeneratedQuestion は 1対多  
  1人のユーザーは複数のAI生成問題を所有できる。

- SimplifiedQuestion と SimplifiedAiGeneratedQuestion は 1対多  
  1つのマスタ問題から複数のAI生成問題が作成される可能性がある。

---

### 繁體中文側

- User と TraditionalFavorite は 1対多

- TraditionalQuestion と TraditionalFavorite は 1対多  
  1つの繁體中文マスタ問題は複数ユーザーからお気に入り登録される可能性がある。

- User と TraditionalStudyHistory は 1対多  
  1人のユーザーは複数の繁體中文マスタ問題について学習履歴を持つ。

- TraditionalQuestion と TraditionalStudyHistory は 1対多  
  1つの繁體中文マスタ問題は複数ユーザーによって学習される。

- User と TraditionalQuestion は TraditionalFavorite を介して多対多の関係を持つ。

- User と TraditionalQuestion は TraditionalStudyHistory を介して多対多の関係を持つ。

- User と TraditionalAiGeneratedQuestion は 1対多  
  1人のユーザーは複数のAI生成問題を所有できる。

- TraditionalQuestion と TraditionalAiGeneratedQuestion は 1対多  
  1つのマスタ問題から複数のAI生成問題が作成される可能性がある。

## 14. 設計方針

- Userは簡体中文・繁體中文で共通とする。
- Userには `USER / ADMIN` の権限を持たせる。
- 簡体中文と繁體中文のQuestionは完全に分離する。
- Favoriteも簡体中文・繁體中文で分離する。
- StudyHistoryも簡体中文・繁體中文で分離する。
- AiGeneratedQuestionも簡体中文・繁體中文で分離する。
- 簡体中文と繁體中文の問題IDに対応関係を持たせない。
- Favoriteはお気に入り登録された問題のみレコードを保持する。
- お気に入り解除時はFavoriteレコードを削除する。
- マスタ問題の学習履歴はユーザーごとに保存する。
- StudyHistoryには各マスタ問題の最新評価を保持する。
- 評価は `HARD / GOOD / EASY` を基本とする。
- AI生成問題は生成しただけではDBへ保存しない。
- AI生成問題はユーザーが理解度を与えた場合に限り保存する。
- AI生成問題は必ず生成したユーザーと関連付ける。
- AI生成問題は他ユーザーから参照できないようにする。
- AI生成問題をマスタQuestionへ追加しない。
- AI生成問題は通常学習では使用しない。
- AI生成問題はユーザー自身の復習対象として利用できる。
- AI生成対象マスタ問題は `allow_ai_variation` により明示的に区別する。
- AI生成では、人間が定義したテンプレートおよび生成制御情報を使用する。
- AI生成制御情報は問題単位で管理する。
- AI共通設定は問題単位の設定から分離する。
- 管理者は簡体中文・繁體中文双方のマスタ問題およびAI生成設定を管理できる。
