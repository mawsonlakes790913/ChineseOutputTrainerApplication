# 画面設計書

# 1. 共通画面仕様

## 1.1 共通ヘッダー

本アプリケーションの主要画面には共通ヘッダーを表示する。

共通ヘッダーでは、アプリケーション名に加えて、現在の学習対象言語およびサイト表記言語を確認・変更できるようにする。

### 表示項目

- アプリケーション名
- 現在の学習対象言語
- 学習対象言語の変更
- 現在のサイト表記言語
- サイト表記言語の変更
- ログインユーザー情報
- ユーザーメニュー

概念的な表示例：

```text
中文造句工坊    学習対象：台湾華語 ▼    日本語 ▼
```

## 1.2 学習対象言語

学習対象言語は、ユーザーがどの中国語を学習するかを決定する設定である。

以下の2種類から選択する。

- 大陸普通話
- 台湾華語（國語）

学習対象言語によって、以下を切り替える。

- 通常学習で取得する問題
- 復習対象となる問題
- 問題一覧に表示する問題
- AI生成時に使用するLanguage Profile
- AI生成時に使用する語彙・表現
- 学習履歴
- お気に入り
- 文法・構造（Structure）の説明

Structureの文法・構造名は、大陸普通話と台湾華語で共通して使用する。

一方、Structureの説明については、大陸普通話向けと台湾華語向けの2種類を保持する。

説明を表示する際には、現在の学習対象言語に応じて使用する説明を切り替える。

```text
学習対象言語

├── 大陸普通話
│   └── description_zh_cn
│
└── 台湾華語
    └── description_zh_tw

一度選択した学習対象言語は保持し、画面遷移のたびに選択する必要がないものとする。

また、ユーザーが現在どちらを学習しているのかを確認できるよう、主要画面では現在の学習対象言語を分かりやすく表示する。

## 1.3 サイト表記言語

サイト表記言語は、画面上の説明文、ボタン、メニューなどのUI表示に使用する言語を決定する設定である。

以下の4言語に対応する。

- 日本語
- English
- 简体中文
- 繁體中文

サイト表記言語と学習対象言語は独立した設定として扱う。

例えば、

```text
サイト表記：日本語
学習対象：台湾華語
```

や、

```text
サイト表記：简体中文
学習対象：台湾華語
```

といった組み合わせも可能とする。

学習対象言語を変更しても、サイト表記言語は自動的に変更しない。

同様に、サイト表記言語を変更しても学習対象言語は変更しない。

# G01 トップ画面

## 概要

本アプリケーションの入口となる画面。

現在設定されている学習対象言語を確認したうえで、通常学習・AI生成学習・復習を選択できる。

従来のように大陸普通話と台湾華語で学習メニューを分けるのではなく、現在設定されている学習対象言語を各学習機能で共通して使用する。

ログイン状態によって表示するメニューを切り替える。

## レイアウト

### 共通

- 現在の学習対象言語
- 学習対象言語の変更
- 通常学習
- AIによる学習
- 復習
- このアプリについて

### 未ログイン時

- ログイン
- 新規登録

### ログイン時

- メニュー

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 選択項目 | 大陸普通話・台湾華語から現在の学習対象を選択する |
| 通常学習 | リンク | 通常学習メニューへ遷移する |
| AIによる学習 | リンク | AI出題メニューへ遷移する |
| 復習 | リンク | 復習メニューへ遷移する |
| ログイン | リンク | ログイン画面へ遷移する |
| 新規登録 | リンク | 新規登録画面へ遷移する |
| メニュー | リンク | ユーザーメニューへ遷移する |
| このアプリについて | リンク | G21へ遷移する |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 通常学習 | G02 通常学習メニュー |
| AIによる学習 | G04 AI出題メニュー または G08 ログイン画面 |
| 復習 | G06 復習メニュー または G08 ログイン画面 |
| ログイン | G08 ログイン画面 |
| 新規登録 | G09 新規登録画面 |
| メニュー | G10 ユーザーメニュー |
| このアプリについて | G21 このアプリについて |

## 備考

- 通常学習は未ログインでも利用可能。
- AI生成学習および復習はログイン必須。
- 学習対象言語は各学習機能で共通して使用する。
- 大陸普通話と台湾華語で画面そのものは分けない。
- 学習対象言語に応じて取得する問題データを切り替える。
- 「メニュー」はログイン時のみ表示する。

# G02 通常学習メニュー

## 概要

固定されたマスタ問題を使用する通常学習の出題条件を選択する画面。

現在設定されている学習対象言語に対応する問題を対象とする。

## レイアウト

- 現在の学習対象言語
- 難易度選択
- 出題順選択
  - 順番
  - ランダム
- 学習範囲選択
- 未学習問題から学習
- 学習開始ボタン
- トップへ戻る

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | 現在の学習対象を表示する |
| 難易度 | チェックボックス | 出題対象となる難易度を選択する |
| 順番 | ラジオボタン | 対象問題を登録順等で出題する |
| ランダム | ラジオボタン | 対象問題をランダムに出題する |
| 学習範囲 | 選択項目 | 順番出題時の対象範囲を指定する |
| 未学習問題 | 選択項目 | 未学習問題のみを対象とする |
| 学習開始 | ボタン | 条件に基づいて通常学習を開始する |
| トップへ戻る | ボタン | トップ画面へ戻る |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 学習開始 | G03 通常学習問題画面 |
| トップへ戻る | G01 トップ画面 |

## 備考

- 現在設定されている学習対象言語に対応する問題のみを対象とする。
- 詳細な難易度区分や学習範囲の単位は別途確定する。

# G03 通常学習問題画面

## 概要

固定されたマスタ問題を使用して瞬間中作文を行う画面。

現在設定されている学習対象言語に対応する問題を出題する。

## レイアウト

- 現在の学習対象言語
- 問題文
- 文法・表現条件
- ヒント
- 回答表示ボタン

回答表示後：

- 模範解答
- 発音表記
- 別解
- 別解の発音表記
- お気に入りボタン
- Hard
- Good
- Easy
- 中断

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | 現在出題されている問題の学習対象を表示する |
| 問題文 | ラベル | 日本語の問題文を表示する |
| 条件 | ラベル | 学習対象となる文法・表現などを表示する |
| ヒント | ボタン | ヒントを表示する |
| 回答表示 | ボタン | 中国語の模範解答を表示する |
| 別解 | ラベル | 登録されている場合のみ表示する |
| お気に入り | ボタン | 問題のお気に入り状態を変更する |
| Hard | ボタン | 理解度をHardとして記録する |
| Good | ボタン | 理解度をGoodとして記録する |
| Easy | ボタン | 理解度をEasyとして記録する |
| 中断 | ボタン | 学習を中断する |
| 発音表記 | ラベル | 現在の発音表記設定に応じて拼音・注音を表示する。表示なしの場合は表示しない |
| 別解の発音表記 | ラベル | 別解が登録されている場合、現在の発音表記設定に応じて拼音・注音を表示する。表示なしの場合は表示しない |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| Hard / Good / Easy | G03 通常学習問題画面 |
| 中断 | G02 通常学習メニュー |
| 最後の問題終了 | G23 学習完了画面 |

## 備考

- 未ログイン時は学習履歴・お気に入りを保存しない。
- ログイン時は自己評価を学習履歴へ保存する。
- 現在の学習対象言語に対応する問題のみを出題する。

# G04 AI出題メニュー

## 概要

AI生成問題による学習条件を選択する画面。

ログインユーザーのみ利用可能。

現在設定されている学習対象言語に対応するLanguage Profileを使用してAI問題を生成する。

## レイアウト

- 現在の学習対象言語
- 難易度選択
- 出題条件
- AI生成対象設定
- 学習開始ボタン
- トップへ戻る

将来的な機能：

- ジャンル選択

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | AI生成で使用する現在の学習対象を表示する |
| 難易度 | チェックボックス | AI生成の基となる問題の難易度を選択する |
| 出題条件 | 選択項目 | AI生成対象となる問題条件を指定する |
| ジャンル | チェックボックス | 生成文章の分野を指定する（将来実装候補） |
| 学習開始 | ボタン | AI生成学習を開始する |
| トップへ戻る | ボタン | トップ画面へ戻る |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 学習開始 | G05 AI出題問題画面 |
| トップへ戻る | G01 トップ画面 |

## 備考

- `allow_ai_variation = true`のマスタ問題のみAI生成対象とする。
- 現在の学習対象言語に対応するマスタ問題を使用する。
- 現在の学習対象言語に対応するLanguage ProfileをAIへ渡す。
- ジャンル指定はVersion 1.0では実装しない可能性がある。

# G05 AI出題問題画面

## 概要

マスタ問題とテンプレートを基にAIが生成した問題で学習する画面。

現在の学習対象言語に対応するLanguage Profileを使用して生成された問題を出題する。

## レイアウト

- 現在の学習対象言語
- AI生成された問題文
- 条件
- ヒント
- 回答表示
- Hard
- Good
- Easy
- 中断

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | AI生成に使用された学習対象を表示する |
| 問題文 | ラベル | AI生成問題に対応する日本語問題文を表示する |
| 条件 | ラベル | 学習対象となる構文・表現を表示する |
| 回答表示 | ボタン | AI生成された模範解答を表示する |
| Hard / Good / Easy | ボタン | 学習結果を記録して次へ進む |
| 中断 | ボタン | AI生成学習を中断する |
| 発音表記 | ラベル | AI生成された中国語に対応する拼音または注音を表示する |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| Hard / Good / Easy | G05 AI出題問題画面 |
| 中断 | G04 AI出題メニュー |
| 学習完了 | G23 学習完了画面 |

## 備考

- AI生成結果はマスタ問題とは区別して扱う。
- AI生成問題の学習履歴をどの単位で保存するかはDB設計時に確定する。
- AI応答失敗時の再試行・エラー処理については設計段階で検討する。
- AI生成中に学習対象言語を変更しても、開始済みの学習では開始時の学習対象を維持する。

- ユーザーID
- パスワード
- Remember-me
- ログイン
- 新規登録

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| ユーザーID | テキストボックス | ログインIDを入力する |
| パスワード | パスワード入力 | パスワードを入力する |

| 新規登録 | リンク | 新規登録画面へ遷移する |

# 24. 開発途中で追加した画面設計

## 24.1 拼音・注音表示への対応

**追加日：2026年8月15日**

当初の画面設計では、中国語の模範解答のみを表示し、
発音表記は表示しない設計としていた。

その後、学習時に中国語の発音を確認できるようにするため、
拼音（Pinyin）および注音符號（Zhuyin / Bopomofo）の表示に対応する。

## 24.2 発音表記の表示

通常学習・AI生成学習・復習では、
回答表示後に中国語の模範解答とあわせて発音表記を表示する。

表示する発音表記は、ユーザーの発音表記設定によって決定する。

```text
PINYIN
  ↓
拼音を表示

ZHUYIN
  ↓
注音を表示

---

## 24.3 別解の拼音・注音表示への対応

**追加日：2026年8月16日**

拼音・注音表示への対応後、別解が存在する問題についても発音を確認できるようにするため、別解の発音表記にも対応する。

### 通常学習問題画面

別解が登録されている場合、別解とあわせてその発音表記を表示する。

表示する発音表記は、本解答と同じ発音表記設定を使用する。

```text
PINYIN
├── 模範解答 → 拼音
└── 別解     → 拼音

ZHUYIN
├── 模範解答 → 注音
└── 別解     → 注音

NONE
├── 模範解答 → 発音表記なし
└── 別解     → 発音表記なし
```

別解が存在しない場合は、別解および別解の発音表記を表示しない。

### アドミン専用問題追加・編集画面

別解を登録する場合、その別解に対応する以下の発音情報も管理できるようにする。

- 別解の拼音
- 別解の注音

G17「アドミン専用問題追加画面」に入力項目を追加し、G18「アドミン専用問題編集画面」についてもG17と同じ入力項目を使用する。

## 24.4 文法・構造（structure）への対応

**追加日：2026年8月23日**

問題を文法・構造によって客観的に分類し、復習時の出題条件や問題検索に利用できるようにするため、Questionに `structure` を追加する。

`structure` は、模範解答となる中国語文そのものの根幹となる文法・構造を表す。

例えば、

```text
他笑着跟我说话。
→ 動態助詞（着）

这么多菜，我们吃不完。
→ 可能補語

我听懂了。
→ 結果補語
```

のように分類する。

既存の `condition` は、開発者・出題者が問題に設定する解答条件・ヒントであり、`structure` とは役割が異なる。

```text
structure
└── 中国語文そのものの根幹となる文法・構造
    └── 客観的な分類

condition
└── その問題をどのように解答させるか
    └── 開発者・出題者が設定する主観的な条件・ヒント
```

画面上では、`structure` を主に問題の検索・絞り込みに使用し、`condition` は従来どおり問題出題時の条件として表示する。

### G25 文法・構造ガイド

#### 概要

`structure` として使用される主要な中国語の文法・構造を簡潔に紹介する画面。

中国語では、学習者が文法・構造そのものを理解していても、「動態助詞」「可能補語」「結果補語」などの正式な分類名称を把握しているとは限らない。

そのため、実際の中国語表現と `structure` の名称を対応させて確認できる補助ページを提供する。

本画面は詳細な中国語文法教材や文法辞典を提供することを目的とせず、`structure` として使用される名称を理解するための簡潔なガイドとする。

#### レイアウト

```text
文法・構造ガイド

動態助詞（着）
  簡単な説明
  例文

可能補語
  簡単な説明
  例文

結果補語
  簡単な説明
  例文

方向補語
  簡単な説明
  例文

把構文
  簡単な説明
  例文

...

トップへ戻る
```

各文法・構造について、以下の情報を簡潔に掲載する。

- `structure` の名称
- 簡単な説明
- 代表的な中国語例文
- 必要に応じた日本語訳・補足

例えば、

```text
可能補語

動作や結果が実現できるか、できないかを表す形式。

这么多菜，我们吃不完。
（こんなにたくさんの料理は食べきれません。）

吃得完 → 食べきれる
吃不完 → 食べきれない
```

のように表示する。

各 `structure` に個別の解説画面を設けるのではなく、主要な文法・構造を本画面内で一覧的に確認できる構成とする。

#### 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 文法・構造名 | 見出し | `structure` として使用する文法・構造の名称を表示する |
| 説明 | テキスト | 文法・構造の意味や基本的な使い方を簡潔に説明する |
| 例文 | テキスト | 文法・構造を使用した代表的な中国語例文を表示する |
| 日本語訳・補足 | テキスト | 必要に応じて例文の日本語訳や補足を表示する |
| トップへ戻る | ボタン | G01トップ画面へ戻る |

#### 画面遷移

| 操作 | 遷移先 |
|---|---|
| トップへ戻る | G01 トップ画面 |

#### 備考

- 未ログインでもアクセス可能。
- Home画面から直接遷移できるものとする。
- 文法・構造ガイドの内容はDBでは管理しない。
- 各 `structure` に個別の解説ページは設けない。
- 主要な文法・構造を1つのページ内で簡潔に紹介する。
- 詳細な文法教材ではなく、`structure` の名称と実際の中国語表現を結びつけるための補助ページとして扱う。

### 24.5 Structureのマスタデータ化

**設計変更日：2026年8月24日**

24.4では、Questionに `structure` を追加し、復習メニュー、問題一覧、問題追加・編集画面、文法・構造ガイドで利用する設計とした。

その後、文法・構造による検索機能を実装する中で、「可能補語」「比較構文」「条件複文」などの分類名称だけでは、その文法・構造の内容を判断しにくい場合があることが分かった。

そのため、各文法・構造について簡単な説明を保持し、復習メニューなどから確認できるようにする。

これに伴い、文法・構造をQuestionの文字列属性として直接管理するのではなく、独立したStructureマスタとして管理する設計へ変更する。

概念的には、

```text
Structure
├── 文法・構造ID
├── 文法・構造名
├── 大陸普通話向けの説明
└── 台湾華語向けの説明
        ↑
        │ N:1
Question
        ↑
        │ N:1
Question
```

とする。

文法・構造名は、大陸普通話と台湾華語で共通して使用する。

一方、文法・構造の説明については、大陸普通話向けと台湾華語向けの2種類を保持する。

説明を表示する際には、セッションに保存されている現在の学習対象言語に応じて使用する説明を切り替える。

    session.languageVariant

    ├── MAINLAND
    │   └── description_zh_cn
    │
    └── TAIWAN
        └── description_zh_tw

この説明の切り替えはサイト表記言語とは独立して扱う。

Questionには必ず1つのStructureを関連付ける。

これに伴い、24.4で追加・変更した各画面について、以下のように設計を変更する。

#### G06 復習メニュー

例えば、

```text

      ↓

```

のように表示する。

PCなどマウス操作を行う環境では、文法・構造名にカーソルを合わせることで説明を確認できるUIを基本とする。

タッチ操作などホバーを利用できない環境についても説明を確認できるよう、具体的な表示方法は実装時に決定する。

文法・構造欄は、Structureの種類が増加した場合に画面を大きく占有しないよう、初期状態では一部のみを表示し、ユーザー操作によって全件を展開できるものとする。

    └── description_zh_tw

    原因・理由と、それによって生じる結果を表す複文。

と表示し、台湾華語を学習対象としている場合は、

    原因・理由と、それによって生じる結果を表す複文。

と表示する。

この切り替えはサイト表記言語とは独立して扱う。

    │   └── description_zh_cn
    │
    └── TAIWAN
        └── description_zh_tw

- 日本語訳
- 詳細な補足

#### 変更後の画面設計方針

Structureのマスタデータ化に伴い、以下を画面設計上の方針とする。

- 文法・構造の選択肢はStructureマスタから取得する。
- Questionに文法・構造名を自由入力する画面は設けない。
- Questionの追加・編集では、登録済みStructureから1件を選択する。
- 復習メニューおよび問題検索では、Structureを検索条件として使用する。
- 復習メニューでは、各Structureについて現在の学習対象言語に対応する説明を確認できるようにする。
- 文法・構造ガイドでは、Structureの名称と現在の学習対象言語に対応する説明をDBから取得して表示する。
- Structureの説明を表示する際は、セッションに保存されている現在の学習対象言語に応じて、大陸普通話向けまたは台湾華語向けの説明を使用する。
- Structureの説明の切り替えはサイト表記言語とは独立して扱う。
- 文法・構造ガイド用の詳細な例文や補足の管理方法については、実装時に決定する。
