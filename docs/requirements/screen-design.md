# 画面設計書

# 1. 共通画面仕様

## 1.1 共通ヘッダー

本アプリケーションの主要画面には共通ヘッダーを表示する。

共通ヘッダーでは、アプリケーション名に加えて、現在の学習対象言語およびサイト表記言語を確認・変更できるようにする。

### 表示項目

- アプリケーション名
- 現在の学習対象言語
- 学習対象言語の変更
- 現在のサイト表記言語
- サイト表記言語の変更
- ログインユーザー情報
- ユーザーメニュー

概念的な表示例：

```text
中文造句工坊    学習対象：台湾華語 ▼    日本語 ▼
```

---

## 1.2 学習対象言語

学習対象言語は、ユーザーがどの中国語を学習するかを決定する設定である。

以下の2種類から選択する。

- 大陸普通話
- 台湾華語（國語）

内部的には以下の値を使用する。

```text
MAINLAND
TAIWAN
```

学習対象言語によって、以下を切り替える。

- 通常学習で取得する問題
- 復習対象となる問題
- 問題一覧の初期表示
- AI生成時に使用するLanguage Profile
- AI生成時に使用する語彙・表現
- 学習履歴の対象
- お気に入りの対象
- 文法・構造（Structure）の説明

Structureの文法・構造名は、大陸普通話と台湾華語で共通して使用する。

一方、Structureの説明については、大陸普通話向けと台湾華語向けの2種類を保持する。

説明を表示する際には、現在の学習対象言語に応じて使用する説明を切り替える。

```text
学習対象言語

├── MAINLAND
│   └── description_zh_cn
│
└── TAIWAN
    └── description_zh_tw
```

### ログインユーザーの設定

ログインユーザーについては、学習対象言語をUsersに保存する。

```text
Users.language_variant
```

ユーザーが学習対象言語を変更した場合は、`Users.language_variant` を更新する。

これにより、学習対象言語はログアウトしても失われない。

例えば、

```text
Users.language_variant = TAIWAN

        ↓

ログアウト

        ↓

再ログイン

        ↓

Users.language_variant = TAIWAN
```

となり、前回設定した台湾華語を引き続き学習対象として使用する。

新規ユーザーのデフォルト値は、

```text
MAINLAND
```

とする。

### 未ログインユーザー

通常学習など、未ログイン状態でも利用できる機能では、DBへユーザー設定を保存できない。

そのため、未ログイン時の学習対象言語は一時的な設定として扱う。

デフォルト値は、

```text
MAINLAND
```

とする。

---

## 1.3 発音表記

発音表記は、中国語の模範解答とともに表示する発音情報を決定する設定である。

以下の3種類から選択する。

- 拼音
- 注音
- 表示なし

内部的には以下の値を使用する。

```text
PINYIN
ZHUYIN
NONE
```

それぞれ、

```text
PINYIN
└── 拼音を表示

ZHUYIN
└── 注音を表示

NONE
└── 発音表記を表示しない
```

とする。

ログインユーザーについては、発音表記をUsersに保存する。

```text
Users.pronunciation_type
```

ユーザーが発音表記を変更した場合は、`Users.pronunciation_type` を更新する。

これにより、発音表記についてもログアウト後に設定が失われない。

例えば、

```text
Users.pronunciation_type = ZHUYIN

        ↓

ログアウト

        ↓

再ログイン

        ↓

Users.pronunciation_type = ZHUYIN
```

となる。

新規ユーザーのデフォルト値は、

```text
PINYIN
```

とする。

学習対象言語と発音表記は独立した設定として扱う。

そのため、

```text
MAINLAND + PINYIN
MAINLAND + ZHUYIN
MAINLAND + NONE

TAIWAN + PINYIN
TAIWAN + ZHUYIN
TAIWAN + NONE
```

のすべての組み合わせを許可する。

---

## 1.4 サイト表記言語

サイト表記言語は、画面上の説明文、ボタン、メニューなどのUI表示に使用する言語を決定する設定である。

以下の4言語に対応する。

- 日本語
- English
- 简体中文
- 繁體中文

サイト表記言語と学習対象言語は独立した設定として扱う。

例えば、

```text
サイト表記：日本語
学習対象：台湾華語
```

や、

```text
サイト表記：简体中文
学習対象：台湾華語
```

といった組み合わせも可能とする。

学習対象言語を変更しても、サイト表記言語は自動的に変更しない。

同様に、サイト表記言語を変更しても学習対象言語は変更しない。

また、発音表記についてもこれらとは独立した設定として扱う。

---

## 1.5 ユーザー設定の保持方針

ログインユーザーについて、以下の設定をUsersに保存する。

```text
Users
│
├── language_variant
└── pronunciation_type
```

それぞれ、

```text
language_variant
├── MAINLAND
└── TAIWAN

pronunciation_type
├── PINYIN
├── ZHUYIN
└── NONE
```

を保持する。

デフォルト値は、

```text
language_variant   = MAINLAND
pronunciation_type = PINYIN
```

とする。

これらはユーザーごとの設定であるため、DBへ永続化する。

セッションのみを永続的な保存先として使用しない。

ログイン後は、Usersに保存されている設定を現在のユーザー設定として使用する。

これにより、

```text
設定変更
    ↓
Usersへ保存
    ↓
ログアウト
    ↓
再ログイン
    ↓
Usersから設定を取得
    ↓
前回の設定を継続
```

という動作を実現する。

# G01 トップ画面

## 概要

本アプリケーションの入口となる画面。

現在設定されている学習対象言語を確認したうえで、通常学習・AI生成学習・復習を選択できる。

従来のように大陸普通話と台湾華語で学習メニューを分けるのではなく、現在設定されている学習対象言語を各学習機能で共通して使用する。

ログイン状態によって表示するメニューを切り替える。

## レイアウト

### 共通

- 現在の学習対象言語
- 学習対象言語の変更
- 通常学習
- AIによる学習
- 復習
- 文法・構造ガイド
- このアプリについて

### 未ログイン時

- ログイン
- 新規登録

### ログイン時

- メニュー

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 選択項目 | 大陸普通話・台湾華語から現在の学習対象を選択する |
| 通常学習 | リンク | 通常学習メニューへ遷移する |
| AIによる学習 | リンク | AI出題メニューへ遷移する |
| 復習 | リンク | 復習メニューへ遷移する |
| 文法・構造ガイド | リンク | G25へ遷移する |
| ログイン | リンク | ログイン画面へ遷移する |
| 新規登録 | リンク | 新規登録画面へ遷移する |
| メニュー | リンク | ユーザーメニューへ遷移する |
| このアプリについて | リンク | G21へ遷移する |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 通常学習 | G02 通常学習メニュー |
| AIによる学習 | G04 AI出題メニュー または G08 ログイン画面 |
| 復習 | G06 復習メニュー または G08 ログイン画面 |
| 文法・構造ガイド | G25 文法・構造ガイド |
| ログイン | G08 ログイン画面 |
| 新規登録 | G09 新規登録画面 |
| メニュー | G10 ユーザーメニュー |
| このアプリについて | G21 このアプリについて |

## 備考

- 通常学習は未ログインでも利用可能。
- AI生成学習および復習はログイン必須。
- 大陸普通話と台湾華語で画面そのものは分けない。
- 学習対象言語に応じて取得する問題データを切り替える。
- ログインユーザーが学習対象言語を変更した場合は、Usersの `language_variant` に変更内容を保存する。
- 「メニュー」はログイン時のみ表示する。

# G02 通常学習メニュー

## 概要

固定されたマスタ問題を使用する通常学習の出題条件を選択する画面。

現在設定されている学習対象言語に対応する問題を対象とする。

## レイアウト

- 現在の学習対象言語
- 難易度選択
- 出題順選択
  - 順番
  - ランダム
- 学習範囲選択
- 未学習問題から学習
- 学習開始ボタン
- トップへ戻る

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | 現在の学習対象を表示する |
| 難易度 | チェックボックス | 出題対象となる難易度を選択する |
| 順番 | ラジオボタン | 対象問題を登録順等で出題する |
| ランダム | ラジオボタン | 対象問題をランダムに出題する |
| 学習範囲 | 選択項目 | 順番出題時の対象範囲を指定する |
| 未学習問題 | 選択項目 | 未学習問題のみを対象とする |
| 学習開始 | ボタン | 条件に基づいて通常学習を開始する |
| トップへ戻る | ボタン | トップ画面へ戻る |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 学習開始 | G03 通常学習問題画面 |
| トップへ戻る | G01 トップ画面 |

## 備考

- 現在設定されている学習対象言語に対応する問題のみを対象とする。

# G03 通常学習問題画面

## 概要

固定されたマスタ問題を使用して瞬間中作文を行う画面。

現在設定されている学習対象言語に対応する問題を出題する。

## レイアウト

- 現在の学習対象言語
- 問題文
- 文法・表現条件
- ヒント
- 回答表示ボタン

回答表示後：

- 模範解答
- 発音表記
- 別解
- 別解の発音表記
- お気に入りボタン
- Hard
- Good
- Easy
- 中断

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | 現在出題されている問題の学習対象を表示する |
| 問題文 | ラベル | 日本語の問題文を表示する |
| 条件 | ラベル | 学習対象となる文法・表現などを表示する |
| ヒント | ボタン | ヒントを表示する |
| 回答表示 | ボタン | 中国語の模範解答を表示する |
| 発音表記 | ラベル | 現在の発音表記設定に応じて拼音・注音を表示する。NONEの場合は表示しない |
| 別解 | ラベル | 登録されている場合のみ表示する |
| 別解の発音表記 | ラベル | 別解が存在する場合に現在の発音表記設定に応じて表示する |
| お気に入り | ボタン | 問題のお気に入り状態を変更する |
| Hard | ボタン | 理解度をHardとして記録する |
| Good | ボタン | 理解度をGoodとして記録する |
| Easy | ボタン | 理解度をEasyとして記録する |
| 中断 | ボタン | 学習を中断する |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| Hard / Good / Easy | G03 通常学習問題画面 |
| 中断 | G02 通常学習メニュー |
| 最後の問題終了 | G23 学習完了画面 |

## 備考

- 未ログイン時は学習履歴・お気に入りを保存しない。
- ログイン時は自己評価を学習履歴へ保存する。
- 現在の学習対象言語に対応する問題のみを出題する。
- ログインユーザーの発音表記は `Users.pronunciation_type` を基準とする。

# G04 AI出題メニュー

## 概要

AI生成問題による学習条件を選択する画面。

ログインユーザーのみ利用可能。

現在設定されている学習対象言語に対応するLanguage Profileを使用してAI問題を生成する。

## レイアウト

- 現在の学習対象言語
- 難易度選択
- 出題条件
- AI生成対象設定
- 学習開始ボタン
- トップへ戻る

将来的な機能：

- ジャンル選択

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | AI生成で使用する現在の学習対象を表示する |
| 難易度 | チェックボックス | AI生成の基となる問題の難易度を選択する |
| 出題条件 | 選択項目 | AI生成対象となる問題条件を指定する |
| ジャンル | チェックボックス | 生成文章の分野を指定する（将来実装候補） |
| 学習開始 | ボタン | AI生成学習を開始する |
| トップへ戻る | ボタン | トップ画面へ戻る |

## 備考

- `allow_ai_variation = true` のマスタ問題のみAI生成対象とする。
- `Users.language_variant` に対応するマスタ問題を使用する。
- `Users.language_variant` に対応するLanguage ProfileをAIへ渡す。
- ユーザーごとのAI生成設定は現時点では設けない。
- ジャンル指定はVersion 1.0では実装しない可能性がある。

# G05 AI出題問題画面

## 概要

マスタ問題とテンプレートを基にAIが生成した問題で学習する画面。

学習開始時の学習対象言語に対応するLanguage Profileを使用して生成された問題を出題する。

## レイアウト

- 現在の学習対象言語
- AI生成された問題文
- 条件
- ヒント
- 回答表示
- 発音表記
- Hard
- Good
- Easy
- 中断

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | AI生成に使用された学習対象を表示する |
| 問題文 | ラベル | AI生成問題に対応する日本語問題文を表示する |
| 条件 | ラベル | 学習対象となる構文・表現を表示する |
| 回答表示 | ボタン | AI生成された模範解答を表示する |
| 発音表記 | ラベル | 発音表記設定に応じて拼音・注音を表示する。NONEの場合は表示しない |
| Hard / Good / Easy | ボタン | 学習結果を記録して次へ進む |
| 中断 | ボタン | AI生成学習を中断する |

## 備考

- AI生成結果はマスタ問題とは区別して扱う。
- AI生成中にユーザー設定が変更されても、開始済みの学習では開始時の学習対象言語を維持する。
- 表示する発音表記はログインユーザーの `Users.pronunciation_type` を基準とする。

# G06 復習メニュー

## 概要

学習履歴を利用して復習対象を絞り込む画面。

現在設定されている学習対象言語の学習履歴を対象とする。

## レイアウト

- 現在の学習対象言語
- 理解度
  - Hard
  - Good
  - Easy
- 難易度
- 文法・構造
- お気に入り条件
- 出題順
- 復習開始
- トップへ戻る

## 項目定義

| 項目名 | 種別 | 説明 |
|---|---|---|
| 学習対象言語 | 表示項目 | 復習対象となる現在の学習対象を表示する |
| 理解度 | チェックボックス | Hard / Good / Easyを指定する |
| 難易度 | チェックボックス | 復習対象の難易度を指定する |
| 文法・構造 | チェックボックス | Structureに基づいて復習対象を絞り込む |
| お気に入り条件 | 選択項目 | 全て・お気に入り・非お気に入りを指定する |
| 出題順 | ラジオボタン | 順番またはランダムを指定する |
| 復習開始 | ボタン | 条件に基づいて復習を開始する |
| トップへ戻る | ボタン | トップ画面へ戻る |

## 文法・構造

文法・構造は複数選択可能とする。

```text
文法・構造

[すべて選択] [すべて解除]

☑ 平叙文
☑ 把構文
☑ 可能補語
☑ 比較構文
☑ 条件複文
...
```

選択肢はStructureマスタから取得する。

各Structureについて、現在の学習対象言語に対応する説明を確認できるようにする。

```text
Users.language_variant = MAINLAND
└── Structure.description_zh_cn

Users.language_variant = TAIWAN
└── Structure.description_zh_tw
```

## 備考

- 現在設定されている学習対象言語に対応する学習履歴のみを対象とする。
- Structureの説明はサイト表記言語ではなく学習対象言語によって切り替える。

の場合は、

```text
Question.language_variant = MAINLAND
```

```text
Users.language_variant = TAIWAN
```

の場合は、

```text
Question.language_variant = TAIWAN
```

- 文法・構造

```text
└── zhuyin

NONE
└── 表示しない
```

```text

└── alternative_answer_pinyin

ZHUYIN
└── alternative_answer_zhuyin

NONE
└── 表示しない
```

とする。

## 24.6 ユーザー設定の永続化

**追加日：2026年8月27日**

当初、学習対象言語および発音表記は、アプリケーション利用中に変更できる設定として実装していた。

しかし、設定値をセッション上でのみ保持した場合、

```text
ログイン
    ↓
学習対象言語をTAIWANへ変更
    ↓
台湾華語で学習
    ↓
ログアウト
    ↓
セッション破棄
    ↓
再ログイン
    ↓
MAINLANDへ戻る
```

という問題が発生する。

発音表記についても同様に、ユーザーが注音へ変更しても、ログアウト後にデフォルトの拼音へ戻ってしまう。

これらはユーザーが継続的に利用する設定であるため、セッションのみで管理するのは適切ではない。

そこで、Usersに、

```text
language_variant
pronunciation_type
```

を追加し、ユーザーごとの設定としてDBへ永続化する。

```text
Users
│
├── language_variant
│   ├── MAINLAND
│   └── TAIWAN
│
└── pronunciation_type
    ├── PINYIN
    ├── ZHUYIN
    └── NONE
```

デフォルト値は、

```text
language_variant   = MAINLAND
pronunciation_type = PINYIN
```

とする。

設定変更後は、

```text
G24 設定画面
    ↓
設定変更
    ↓
Usersを更新
    ↓
DBへ保存
```

という処理を行う。

ログイン時には、

```text
認証成功
    ↓
Usersを取得
    ↓
language_variantを取得
pronunciation_typeを取得
    ↓
現在のユーザー設定として使用
```

とする。

これにより、

```text
Users
├── language_variant   = TAIWAN
└── pronunciation_type = ZHUYIN

        ↓

ログアウト

        ↓

再ログイン

        ↓

Users
├── language_variant   = TAIWAN
└── pronunciation_type = ZHUYIN
```

となり、前回の設定を継続できる。

### セッションとの関係

この変更によって、セッションを一切使用しなくなるわけではない。

アプリケーション利用中の現在値として、

```text
languageVariant
pronunciationType
```

をセッションへ保持する実装は可能である。

ただし、

```text
セッション
└── 一時的な現在値

Users
└── 永続的なユーザー設定
```

と役割を明確に分ける。

ログアウトによってセッションが破棄されても、Usersに設定が保存されているため、再ログイン時に復元できる。

### G24設定画面

この設計変更に伴い、G24を正式なユーザー設定画面として定義する。

Version 1.0で扱う設定は、

```text
1. 学習対象言語
2. 発音表記
```

の2項目とする。

AI問題生成については、ユーザーごとの設定項目を現時点では設けない。

AI生成に使用するLanguage Profileは、

```text
Users.language_variant
```

によって自動的に決定する。

そのため、AI問題生成のためだけに、

```text

AI生成方言
AI用発音設定
```

などをG24へ追加しない。
