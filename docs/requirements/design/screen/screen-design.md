# 画面設計書

Chinese Output Forgeの画面構成と共通UI仕様をまとめる。画面ごとの入力項目、バリデーション、画面遷移などは[画面詳細設計書](screen-design-details.md)を参照。開発途中の変更記録は[画面設計変更履歴](screen-design-history.md)に分離した。

> この資料は元の画面設計書を整理したものであり、記載内容のすべてが現行実装と一致することを保証するものではない。実装状況はアプリケーションとソースコードを優先する。

## 共通画面仕様

- **学習対象言語**：大陸普通話（`MAINLAND`）／台湾華語（`TAIWAN`）。問題・AI生成プロファイル・Structureの説明を切り替える。
- **発音表記**：拼音（`PINYIN`）／注音（`ZHUYIN`）／表示なし（`NONE`）。学習対象言語とは独立して選択する。
- **サイト表記言語**：日本語／英語／簡体字中国語／繁体字中国語。学習対象言語と独立する。
- **ログインユーザーの設定**：学習対象言語と発音表記を`Users.language_variant`、`Users.pronunciation_type`に保存する。
- **未ログイン時**：学習対象言語は一時設定として扱い、通常学習を利用できる。学習履歴やお気に入りは保存しない。
- **権限制御**：AI学習・復習などはログインが必要。管理機能は`ROLE_ADMIN`に限定する。

## 主要な画面フロー

- **通常学習**：G01 → G02 → G03 → G23
- **AI生成学習**：G01 → G04 → G05 → G23
- **復習**：G01 → G06 → G07 → G23
- **アカウント**：G08／G09、G12〜G14、G20、G26〜G28
- **管理者機能**：G15 → G16〜G19

画面遷移の条件、各画面の操作項目・入力チェックは詳細設計書に記載する。
