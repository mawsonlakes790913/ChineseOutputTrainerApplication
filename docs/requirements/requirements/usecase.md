# ユースケース図

![ユースケース図](../../images/usecase.png)

## 概要

本システムでは、学習者が以下の機能を利用できる。

- 通常学習する
- AI生成問題で学習する
- 復習する
- 問題一覧を確認する
- 学習状況を管理する
- ユーザー情報を管理する

また、管理者は以下の機能を利用できる。

- 問題を管理する
- ユーザーを管理する

## ログイン要件

以下の機能はログインユーザーのみ利用可能とする。

- AI生成問題で学習する
- 復習する
- 問題一覧を確認する
- 学習状況を管理する
- ユーザー情報を管理する

管理者向け機能についても、管理者権限を持つユーザーとしてのログインを必須とする。

通常学習はログインせずに利用できる。

## 補足

- 「通常学習する」には、順番に出題する、ランダムに出題する、難易度を指定して出題するなどの学習方法を含む。
- 「AI生成問題で学習する」は、マスタ問題とテンプレートを基にAIが生成した問題を使用して学習する機能を表す。
- 「復習する」は、過去の学習履歴や理解度などを基に問題を再出題する機能を表す。
- 「問題一覧を確認する」は、閲覧可能な問題を一覧表示し、検索・絞り込みを行う機能を表す。ユーザーが作成する問題リストの管理は関連機能として扱う。
- 「学習状況を管理する」には、問題ごとの学習履歴・理解度の確認や変更、お気に入り登録・解除などを含む。
- 「ユーザー情報を管理する」には、ログインID、パスワード、メールアドレスなどのアカウント情報の変更を含む。
- 「問題を管理する」には、管理者による問題の確認、追加、編集、削除、およびAI生成に必要なテンプレート・生成制御情報の管理を含む。
- 「ユーザーを管理する」には、管理者によるユーザー情報の確認、アカウントの凍結・解除、削除を含む。
- 大陸普通話／台湾華語の選択と拼音・注音の表示設定は、各学習機能で共通利用する設定として扱い、ユースケース図には含めない。
