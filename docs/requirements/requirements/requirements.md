# 要件定義書 — Chinese Output Forge

> 本書は現在の要件の概要を示す。具体的な振る舞いは[要件詳細](requirements-detail.md)、追加・変更の経緯は[要件変更履歴](requirements-history.md)を参照。

## 1. 背景と解決する課題

中国語の文法や語彙を理解していても、日本語を見てすぐに中国語を組み立てられない学習者を支援する。固定例文の反復だけでは解答を丸暗記しやすいため、**同じ文法・構文を異なる文脈で使う練習**を可能にする。

## 2. システムの目的と特徴

- 日本語の出題文から中国語を瞬間的に組み立てる練習を提供する。
- 固定問題による反復、苦手問題の復習、AIによるバリエーション生成を組み合わせる。
- AIは人間が用意したマスタ問題とテンプレートに基づいて生成し、学習対象の構文を維持する。
- 大陸普通話と台湾華語を別の問題データとして扱い、地域ごとの語彙・表現を区別する。
- 解答はユーザーが自分で確認・評価する。AIによる作文採点や音声による発音評価は基本機能に含めない。

## 3. 想定利用者と利用場面

基本的な中国語文法・語彙を学習済みで、知識を実際のアウトプットにつなげたい学習者。自宅で声に出す学習のほか、通勤・休憩時間などでの短時間学習を想定する。

## 4. 機能要件

| 機能 | 要件の概要 |
| --- | --- |
| 通常学習 | 登録済み問題の出題、模範解答表示、難易度別の学習、理解度の記録 |
| 復習 | 学習結果、難易度、文法・構造、お気に入りなどで問題を絞り込んで再学習 |
| AI問題生成 | マスタ問題とテンプレートから、構文を維持した別の問題を生成 |
| お気に入り | 問題を登録し、再表示・再学習に利用 |
| ユーザー機能 | 登録・認証、設定保存、メールアドレス・パスワード管理、パスワードリセット |
| 管理者機能 | 問題の追加・編集、ユーザー一覧・凍結・解除・削除 |
| 文法・構造 | 問題の文法分類、説明の表示、検索・復習への利用 |
| 言語設定 | 学習対象言語とサイト表記言語を独立して選択 |
| 発音表記 | 拼音・注音・非表示の切り替え。別解にも同じ表示設定を適用 |

各機能の詳細条件は[要件詳細](requirements-detail.md)に記載する。

## 5. 言語対応

- **学習対象**：大陸普通話（`MAINLAND`）、台湾華語（`TAIWAN`）。出題データとAI生成用Language Profileを切り替える。
- **サイト表記**：日本語、英語、簡体中文、繁體中文。学習対象言語とは独立する。
- **発音表記**：拼音（`PINYIN`）、注音（`ZHUYIN`）、表示なし（`NONE`）。学習対象言語とは独立する。
- 学習対象言語と発音表記はユーザー設定として保持し、再ログイン後も引き継ぐ。

## 6. AI生成の基本要件

- AI生成対象かどうかを問題単位で制御する。
- テンプレートとプレースホルダにより変更可能な範囲を指定する。
- 学習ポイント、自然な中国語、地域に合った語彙・文字体系を維持する。
- 直近の生成結果を参照し、同一・類似した問題の繰り返しを抑制する。

## 7. 対象範囲

**基本機能**：通常学習、復習、お気に入り、学習履歴、認証、問題管理、AI生成および生成条件の制御。

**基本機能の対象外**：AIによる中国語作文の採点、音声入力による発音・会話評価、複雑なアニメーション。

**将来の検討対象**：ジャンル別AI生成、学習統計、間隔反復、音声関連機能など。これらは実装済み要件とは区別する。

## 8. 非機能要件

| 分野 | 基本方針 |
| --- | --- |
| セキュリティ | 認証・認可、CSRF対策、適切なパスワード管理 |
| 性能 | 学習操作で過度な待ち時間を生じさせない。AI生成の外部通信を考慮 |
| ログ | 障害原因や動作状況を調査できるログを記録 |
| 保守性 | プロンプト、Language Profile、テンプレート、問題データを変更しやすく管理 |
