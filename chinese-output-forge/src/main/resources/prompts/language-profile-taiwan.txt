# Language Profile: TAIWAN

この問題は、台湾で使用される標準的な國語（台湾華語）として生成してください。

以下のルールを必ず守ってください。

1. **台湾で標準的に使用される正体字（繁体字）を使用してください。**

   中国大陸の簡体字を使用しないでください。

2. **台湾で一般的かつ自然に使用される語彙を使用してください。**

   中国大陸の普通話で一般的であっても、台湾では通常別の語彙を使用する場合、台湾で一般的な語彙を優先してください。

   例えば、

   ```text
   タクシー
   中国大陸：出租车
   台湾：計程車

   地下鉄
   中国大陸：地铁
   台湾：捷運
   ```

   のような地域差を考慮してください。

3. **単に簡体字を繁体字へ変換するだけではなく、台湾華語として自然な語彙・言い回しを使用してください。**

   語彙の選択、語の組み合わせ、日常的な表現、口語表現について、台湾で実際に自然に使用される國語を基準としてください。

4. **発音は台湾の標準的な國語の発音を基準としてください。**

   同じ漢字でも中国大陸の普通話と台湾の國語で標準的な発音が異なる場合は、台湾の発音を使用してください。

   例えば、

   ```text
   垃圾
   → lèsè
   → ㄌㄜˋ ㄙㄜˋ

   企業
   → qìyè
   → ㄑㄧˋ ㄧㄝˋ
   ```

   のようにしてください。

5. `pinyin`についても、中国大陸の普通話の発音を機械的に付与するのではなく、**台湾の國語として採用した発音を拼音で表記**してください。

6. `zhuyin`は、生成した中国語文を**台湾の標準的な國語で発音した場合の発音**に正確に対応させてください。

7. 中国大陸と台湾の両方で使用される語であっても、標準的な発音が異なる場合は、台湾の國語における発音を採用してください。

8. 元の`chineseText`に存在する表現であっても、AIによって新しく置き換えるプレースホルダ部分については、このLanguage Profileに従って字体・語彙・表現・発音を選択してください。
