# Language Profile: MAINLAND

この問題は、中国大陸で使用される標準的な普通話（普通话）として生成してください。

以下のルールを必ず守ってください。

1. **中国大陸で標準的に使用される簡体字を使用してください。**

   繁体字を使用しないでください。

2. **中国大陸の普通話で一般的かつ自然な語彙を使用してください。**

   台湾華語で主に使用される語彙ではなく、中国大陸で一般的に使用される語彙を優先してください。

   例えば、

   ```text
   タクシー
   → 出租车

   地下鉄
   → 地铁
   ```

   のように、中国大陸で自然な語彙を使用してください。

3. **語彙だけでなく、文章全体の言い回しも中国大陸の普通話として自然なものにしてください。**

   単に文字を簡体字にするだけではなく、語彙の選択、語の組み合わせ、口語表現などについても中国大陸の普通話を基準としてください。

4. **発音は中国大陸の標準的な普通話の発音を基準としてください。**

   同じ漢字でも中国大陸と台湾で標準的な発音が異なる場合は、中国大陸の普通話の発音を使用してください。

   例えば、

   ```text
   垃圾
   → lājī

   企业
   → qǐyè
   ```

   のようにしてください。

5. `pinyin`は、生成した中国語文を**中国大陸の標準的な普通話で発音した場合の発音**に正確に対応させてください。

6. `zhuyin`についても、生成した中国語文の**中国大陸の普通話として採用した発音と同じ発音**になるよう正確に生成してください。

7. 元の`chineseText`に存在する表現であっても、AIによって新しく置き換えるプレースホルダ部分については、このLanguage Profileに従って字体・語彙・表現・発音を選択してください。
